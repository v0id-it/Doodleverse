## Note
I'm using GameMaker IDE with these creds:
- IDE : **v2024.13.1.192**

- Runtime : **v2024.13.1.242**

You can install the runtime with any IDE version (i believe) in `Preferences > Runtime Feeds > Master` and select on **v2024.13.1.242** or any **v2024.13.x.x** versions.

This is due to newer updates (v2024.14.x.x or more) messes around with Draw GUI and reverses its draw order, which is relatively annoying :)
